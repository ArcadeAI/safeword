# Terminal handoff on completion

**Decision-complete terminal handoffs (ASG60P/#4500):** The `terminal-handoff/v1` contract in `hooks/lib/quality.ts` defines matching decision formats for `Next` and `Need`. When no human choice remains, it uses the shorter `Action` form. Claude Code and Codex use their native Stop re-entry flag, while Cursor uses its loop count, to request at most one correction per response. Claude Code skips correction on a non-editing turn if its last tool call successfully launched background work (`run_in_background` Bash/Agent, or Monitor). The turn is waiting for results. Correction applies to the new turn that receives them (#5765). Existing hard evidence gates take precedence. Malformed inputs and evaluator failures allow the response through. Correction is on by default. To disable it, set `"terminalHandoffCorrection": false` in `.safeword/config.json`. Canonical templates generate the Claude and Codex plugin copies; parity checks keep generated and dogfood copies aligned.
