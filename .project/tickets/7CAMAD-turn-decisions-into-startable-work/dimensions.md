# Dimensions: Turn accepted decisions into startable work

| Dimension                  | Partitions and boundaries                                                                                                                                              |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Input state                | absent plan; reviewed current plan; unreviewed plan; stale plan                                                                                                        |
| Startability               | first step runnable from fresh context; missing test action; hidden design choice                                                                                      |
| Obligation mapping         | accepted behavior; delivery obligation; affected surface                                                                                                               |
| Discovery routing          | execution-only clarification; accepted-decision change; proof-boundary change                                                                                          |
| Ordering                   | dependency order; risk-first probe; parallel work; blocked prerequisite                                                                                                |
| Coding gate                | valid semantic approval; pending or failed review; first RED named                                                                                                     |
| Delivery state             | current implementation; target work; known defect; current-revision proof; earlier-revision proof; partial or structural proof; missing proof; pending human authority |
| Contribution shape         | one coherent pull request; dependency-ordered independently reviewable slices; unowned obligation                                                                      |
| Approval meaning           | startable and provable; implemented; verified; human-approved; merge-authorized                                                                                        |
| Measurement execution      | accepted measurement design; missing instrumentation; missing evidence signal; attempted promise redefinition                                                          |
| Review invalidation        | behavior or scope change; accepted design change; execution-only edit; ordinary Delivery Checklist progress                                                            |
| Implementation-time replan | design-changing decision; sequencing-only decision; preserved valid evidence; first invalidated obligation                                                             |
