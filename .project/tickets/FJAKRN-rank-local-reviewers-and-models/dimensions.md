# Dimensions: Let users rank local reviewers and models

| Dimension | Partitions and boundaries |
| --- | --- |
| Route source | new route list; legacy config compiled with built-in defaults |
| Model selection | explicit valid model; omitted runtime default; invalid model |
| Independence | different runtime; same-author runtime in any position |
| Failure scope | attempt failure; runtime-wide failure; remaining wall-clock deadline cannot fund a route |
| Readiness evidence | installed; compatible; catalogued; proven; known failure |
| Ordering influence | configured order; cached observation |
