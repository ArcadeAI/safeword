# Behavioral dimensions

| Dimension | Partitions and boundaries |
| --- | --- |
| Completion timing | before courtesy wait; after courtesy wait |
| Worker liveness | active; exited without a result; exceeds absolute deadline |
| Source identity | unchanged; changed while running; changed after completion before collection |
| User control | inspect latest or named job; cancel running job |
| Process lifetime | initiating process remains; initiating process exits |
