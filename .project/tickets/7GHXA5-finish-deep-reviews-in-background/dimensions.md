# Behavioral dimensions

| Dimension | Partitions and boundaries |
| --- | --- |
| Completion timing | before courtesy wait; after courtesy wait |
| Worker liveness | active; exited without a result; exceeds absolute deadline |
| Source identity | unchanged; changed then restored byte-identically; changed while running; changed after completion; deleted before collection |
| User control | inspect latest or named job; reject malformed or unknown named job; cancel running job; preserve completed job on cancel |
| Process lifetime | initiating process remains; initiating process exits |
