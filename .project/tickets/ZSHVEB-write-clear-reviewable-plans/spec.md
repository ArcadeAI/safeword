#### plan-implementability.TBU4.ZSHVEB.R1 — One shared technical-writing guide is complete and reviewable

- The canonical source is `packages/cli/templates/guides/llm-writing-guide.md`; its installed path is `.safeword/guides/llm-writing-guide.md`.
- The M1 Safeword CLI reconciliation test installs that schema-owned source, proves the installed bytes equal the canonical bytes, and fails when the installed guide is missing or stale.
- Its required topic set is exactly these six level-two headings, each appearing exactly once: `## Current truth`, `## Decision-first writing`, `## Exact contracts`, `## Scannable structure`, `## LLM authoring and review`, and `## The deletion test`. The check parses Markdown. The document preamble before its first heading and every heading section at levels one through six is a writing-topic candidate when its direct block range before the next heading of any level contains an active paragraph whose first non-whitespace inline node is strong emphasis with text exactly `Weak:`, `Strong:`, or `Source:`—the source spellings are `**Weak:**`, `**Strong:**`, and `**Source:**`. Each marker belongs only to that preamble or its nearest preceding heading. HTML comments, blockquotes, fenced or indented code, list items, and table cells never count. Each required topic must contain all three active markers, while a duplicate required-topic heading or any candidate outside the six fails. Structural headings and nested subsections may organize other material but cannot carry their own exemplar/source markers; the six required topic sections are intentionally the only exemplar-bearing level. This flat exemplar rule prevents a hidden seventh writing rule rather than forbidding subsections themselves.
- A contract test enumerates those six topic headings, requires active `**Weak:**`, `**Strong:**`, and `**Source:**` markers under each, and requires at least one Source paragraph to contain a parsed inline Markdown link whose destination uses `https:` with no credentials or explicit non-443 port. Plain source prose and inline code do not satisfy that mechanical citation floor. The static predicate proves only those URL properties; semantic review must reject a source that is private, local, unresolvable, non-primary, or otherwise unsuitable. The test rejects every candidate outside the six required topics, including the preamble and any other heading level. Guide-change semantic review establishes whether cited material is primary, separately rejects an equivalent seventh topic expressed through alternate exemplar/source labels, identifies every load-bearing normative claim about reader or LLM behavior and rejects it unless directly supported by a topic source, then decides whether each required pair is compact and genuinely contrasting and whether its source actually supports the claim.
- A load-bearing external claim is a normative assertion about reader or LLM behavior used to justify a writing rule, rather than a Safeword-local convention. Each topic contains a `**Source:**` line with either an inline primary-source citation or `Local convention: <reason>`; the guide contains at least one external primary citation overall, and every load-bearing external claim carries one.
