Primary repository-boundary proof for Scenario: A newly shipped component cannot
disappear from coverage, all four outline examples. This component checks
canonical source discovery/registration only. It does not certify all handler
classifications, lane dispositions, generated projections or admission.

git ls-tree at accepted baseline f48275b5e616010f3ce76bf5baf7329603f9ac57.

produced by the checker under test. The unchanged candidate currently has that

command wrapper and helper-agent entrypoint.
