# Inventory native Claude and Cursor delivery registrations

Supporting repository component for Scenario: Coverage includes every supported
host without an author checklist. Full runtime lanes/dispositions and a healthy
completion check remain separate unfinished obligations. Project hooks do not
substitute for native package registrations.

The native Claude plugin compresses SessionStart and UserPromptSubmit into two
dispatch groups. It also includes a native Setup registration. Source discovery
must retain the actual 24 native manifest entries plus 13 group subhandlers
(SessionStart excludes legacy auto-upgrade). Native Cursor contributes eight
extension entries from its actual package manifest producer. Expected per-event
counts were traced independently through current canonical configuration and
producer source, not through the inventory reader being built.

Pure producer refactors were protected first: Claude event-group bytes compare
identical to tracked runtime/event-groups.json and all14 existing catalogue
tests pass; the actual before/after Cursor packages are byte-identical for
every file and all12 existing relocation/dispatch tests pass. No duplicate
manifest body or second event list is introduced in production.

The actual required-check subprocess in an owned repository currently reports
none of these native families. The first exact family-count assertion fails
with NATIVE_PACKAGE_HANDLER_INVENTORY_MISSING. After GREEN, the same real
process must reflect one additional canonical Claude SessionStart hook inside
the native group (without multiplying its single manifest dispatcher), and an
additional native Cursor sessionStart hook. Restore the actual config source
bytes and require all original exact counts again. This discriminates a fixed
event table and ensures both delivery projections use their real producer.

No native package discovery declarations or group-manifest reader have been
implemented before this executable RED review. No native runtime execution,
trust, activation or admission claim is made by these repository-only controls.
