# Native catalogue resource proof boundary

This is the first Cursor row of the accepted native-catalogue outline. Its Then
requires the canonical workflow, referenced guide and packaged helper to work
together through a native invocation. The proof does not claim that the complete
Cursor extension, shipped manifest, guards or continuation have been implemented.
The required group deliberately cannot pass until those separate cases exist.

The baseline lacks a portable-core generator. The test therefore exposes the
existing production catalogue renderer in an independent portable metadata
carrier. The complete construction is declared in cursor-catalogue-probe.ts.
It changes an existing canonical workflow and allowlisted helper in a disposable
template graph; the current production renderer performs all runtime rewrites.
The carrier does not repair paths or supply another content/policy authority.
The future production portable-core writer replaces this baseline projection
through the same fixture entry point. Default shipped Codex identity is unchanged.

The test asserts that the baseline renderer actually turns the template's
project-hook invocation into `project runtime audit-principle-trace` through the
versioned Codex cache. This rewritten command is the one Cursor executes. The
observer matches its actual shell event, rather than the pre-render template.
The candidate runtime and complete helper graph independently execute correctly
from a separate enrolled scratch project before the native trial.

The intended failure is unavailable native catalogue resource binding: Cursor
loads the rendered workflow and guide but cannot reach their available packaged
helper because the current projection addresses a different host's empty cache.
The native workflow/guide markers, visible module failure and actual shell event
must agree. Wrapping a visible path across Accessibility text nodes does not
change its identity; only whitespace is normalized for path comparison.

This isolated failure tests the accepted catalogue/resource obligation. It is
not shipped-manifest evidence, package admission, a substitute for native guard
tests, or completion of the other hosts in the outline. All scenario checkboxes
remain unchecked until their material example rows and required proofs complete.
