## Rule: install-only-trusted-remote-test-workflows.TBU1.R1

- Release contract: parse and assert the real bundled workflow's trigger, permissions, dependency pins, checkout credentials, secret absence, and test topology.
- Table authority model: cross every admitted authority guard with one isolated
  mutation, including omitted and alternate scalar forms.
- Table parser model: reject duplicate keys, aliases/merges, multiple documents,
  and non-mapping structural nodes at each guarded location.
- Table distribution model: independently vary template, package, schema
  registration, and HWZZJ8 ownership bytes and require identity.
- Mutation sensitivity: every stated authority guard has at least one isolated negative fixture.

## Scenario Review Dispositions

- Successful admission, each distinct authority boundary, representative parser
  ambiguity, and byte-drift release failure: `covered` by acceptance scenarios.
- Equivalent scalar/omission mutations and structural-node locations:
  `delegated` to the authority and parser table models.
- Each independently drifting distribution artifact: `delegated` to the
  distribution table model.
