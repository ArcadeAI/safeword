# Dimensions: Migrate planning guidance without disrupting features

| Dimension | Partitions and boundaries |
| --- | --- |
| In-flight state | before implementation with plan; implementing under accepted plan; returning to planning |
| Reality reconciliation | plan matches current implementation; proposed behavior is absent; implemented behavior contradicts the accepted plan; proof belongs to an older revision |
| Planning guide | new install; upgraded install; retired design artifact references |
| Architecture route | local feature decision; significant durable decision; legacy design-file example |
| Data applicability | lifecycle or ownership change; simple schema; entity count; no data-contract change |
| Design depth | routine plan; deep component design; separate artifact request |
| Installed delivery | both phase contracts and artifacts; checklist; PR slicing; real-boundary proof; justified host limitation |
| Complete journey | plain feature prompt; intake; behavior definition; both plans; TDD; verification; checklist; review-ready PR; human merge authority |
