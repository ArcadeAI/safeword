# Behavioral dimensions

| Dimension | Partitions and boundaries |
| --- | --- |
| Delivery position | GREEN with another scenario; final GREEN; whole-ticket review; verify; done |
| Next-step health | healthy; failed dependency/check; authority required; scope or safety decision required |
| Pull-request state | absent; Draft for evidence; Ready promotion; ready-by-default creation |
| Ticket state | active before done; phase done but status open; status done with verification evidence |
| Agent host | Claude Code; OpenAI Codex; Cursor; unsupported cloud lifecycle |
| Resume behavior | uninterrupted continuation; actionable interruption with exact next step; resumed continuation |
