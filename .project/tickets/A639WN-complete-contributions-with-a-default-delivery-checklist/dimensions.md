# Dimensions: Complete contributions with a default delivery checklist

| Dimension | Partitions and boundaries |
| --- | --- |
| Checklist timing | present before execution; absent at first execution; added only after coding |
| Planning prerequisites | accepted scenarios missing; accepted implementation approach missing; both missing with deterministic ordering |
| Default coverage | every default category represented; one category silently omitted |
| Item disposition | completed with evidence; not applicable with reason; human-owned dependency; contributor-controlled work mislabeled as handoff |
| Execution artifact integrity | readable Execution Plan; unreadable Execution Plan must block rather than regenerate or bypass the checklist |
| Work-type scale | feature Execution Plan; task inline execution and test specification; patch minimal record; feature-sized ceremony imposed on small work |
| PR decomposition | several independently provable changes; one coherent change; no slicing decision |
| Readiness state | contributor obligations proven; contributor obligation incomplete; human approval pending; false merge-authority claim |
| Evidence currency | current-revision proof; reusable earlier-revision proof; partial or structural proof; missing proof; evidence class silently upgraded |
| Host parity | skip: YCFFNC in M2 owns installed Claude Code, OpenAI Codex, OpenCode, and Cursor parity; M1 proves the Safeword CLI contract only |
