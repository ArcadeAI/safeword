# Behavioral dimensions

| Dimension | Partitions and boundaries |
| --- | --- |
| Transcript progress | unchanged; append-only preview report; rewritten or identity-mismatched transcript |
| Retrospective result | no findings; pending drafts; acknowledged and drained drafts; failed extraction or filing |
| Session binding | fresh hook binding; Codex environment fallback; bootstrap install or upgrade; stale or ambiguous identity |
| Worktree location | delivery worktree; linked surviving worktree; spool owned by another worktree/session |
| Cleanup state | unchanged exact targets; repository state changed; worktree/ref/remote target changed |
| Filer availability | preferred filer available; unavailable with authenticated fallback; no authenticated provenance |
