# Bounded delivery dimensions

| Dimension | Included partitions | Explicit limit |
| --- | --- | --- |
| Authority | accepted omission, overreach, persona outcomes, unresolved decisions | semantic generalization beyond tested corpora is not proven |
| Evidence | complete, missing field, unknown field, empty value, declared absence | typed declarations do not grant licenses or privacy permission |
| Currency and use | inside/outside canonical region; canonical/corrupt reviewer copy | currency alone never authorizes dispatch |
| Routes | qualified, unknown, weaker, omitted selector, skipped-only, actual failed attempt | existing runtime-default and unverified-author behavior stays bounded |
| Saved observations | terminated worker, valid reuse, stale identity, corrupt output, unsupported mode | headless results do not prove native acceptance |
| Qualification | complete exact Claude matrix, failed Codex matrix, retained provenance | no alias inference or unchanged paid recollection |
| Delivery | source, generated carriers, docs, fixtures, refactors, real CLI, remote CI | no parent, historical-ledger, private/cloud or recovery completion |

This is the user-approved late delivery split of existing implemented work;
scenario projection and current proof cannot manufacture historical TDD evidence.
