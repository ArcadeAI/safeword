# Dimensions: Lean Product Plans

| Dimension | Partitions and boundaries |
| --- | --- |
| Plan owner | epic; standalone feature; child feature |
| Parent reference | declared epic; missing parent; parent is not an epic |
| Milestone reference | declared stable ID; absent ID; unknown ID; renamed ID |
| Parent change | referenced contract changes; editorial prose; research reference; Killer Demo wording |
| Demand evidence | sufficient first-party evidence; explicit request; unresolved decision-critical demand; child feature; cheaper reversible experiment; mandated work; parity work; inconclusive result; unavailable workflow |
| Killer Demo owner | epic; standalone feature; child feature |
| Applicability | required content; optional absent content; inherited content |

Material boundaries map to scenarios below. Nested epics and tracker
synchronization are explicitly out of scope.
