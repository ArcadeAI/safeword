## Test layers

- Parser partitions are unit tests for the shared inspiration parser.
- Intake and implementation transition outcomes are real-hook integration tests.
- Ordering, refresh, safety-boundary, and plain-language guidance are template
  and skill contract tests. Runtime research isolation is outside the claim.
- Automatic operation is proved through schema registration, generated-surface
  parity, and real rejection/acceptance tests for the canonical transition
  hook. Host adapter contracts prove they consume that implementation. Codex
  Cloud gets repository-guidance availability because it exposes no
  Safeword-owned transition hook.

## Baked decisions

- Inspiration reuses the existing Rules and implementation-plan gates; it does
  not add a phase or conversational approval.
- One credible current reference is the content-path minimum. Two to four is an
  adaptive research target for risky decisions, not a structural quota.
- A specific unsuccessful-search record is a valid outcome; a bare skip is not.
- External material is evidence, never agent instruction, and code reuse is
  separately conditioned on compatible rights and obligations.
- Matching ticket/spec markers plus an independent scaffold-origin sentinel
  prevent deletion of the two markers from downgrading v1 work while preserving
  every signal-free pre-v1 ticket across upgrades.
