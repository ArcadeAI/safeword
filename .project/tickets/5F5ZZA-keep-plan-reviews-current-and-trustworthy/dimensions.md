## Named lower-level proof and ownership

R8's new non-passed CLI/TUI guidance rows are target acceptance obligations,
not a current conditional-guidance implementation or native qualification pass.
Proof status must resolve actual version/plugin-bound native lifecycle and
activation artifacts; a fixture boolean or a successful simulated dispatcher
cannot grant authority. Existing profile/status tests check evidence mechanics,
but do not by themselves prove the revised generated-guidance outcomes.

R9's old canonical-direction Given-echo was removed and its closed-policy
authority obligation consolidated with reconciliation refusal. The canonical
owner in PLAN_EXECUTION.md permits only both_plan_reviews, as parsed by
src/planning/phase-contract.ts. It is not a configurable runtime matrix.
The existing declared-change outline retains actual review invalidation
outcomes. This consolidation does not claim to prove a runtime switch among
multiple valid dependency policies, because main supports no such switch.
