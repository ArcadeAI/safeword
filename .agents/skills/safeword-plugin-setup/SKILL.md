---
name: safeword-plugin-setup
description: Restore the Safeword Codex profile plugin for this project.
---

Run `safeword codex migrate` to install or re-enable the profile plugin. Review the installed hooks in Codex Desktop under Settings > Hooks (or with /hooks in the terminal TUI). Fully restart Codex, then resume this task. Run `safeword codex status` to verify this project is protected.
